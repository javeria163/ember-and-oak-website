# Ember & Oak

A static, multi-page restaurant website built with HTML, CSS, and JavaScript for Web Technologies Assignment 01.

## Pages
- `index.html` — Home
- `about.html` — About
- `menu.html` — Menu
- `gallery.html` — Gallery
- `contact.html` — Contact

## Features
- Responsive layout using Flexbox and CSS Grid
- Hamburger navigation menu for mobile
- Accordion-style menu categories
- Image carousel and lightbox gallery
- Client-side contact form validation

## Tech
Pure HTML5, CSS3, and vanilla JavaScript — no frameworks or backend.
